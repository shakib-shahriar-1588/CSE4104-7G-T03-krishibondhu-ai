# Design

The UI designs and user flows for KrishiBondhu AI. The screens share one theme and are shown mainly in Bangla, with sample data for illustration.

## Folders

- `ui-screens/`: desktop screens, mobile screens and style guide
- `user-flow/`: user flow diagrams and development timeline

## Style

- **Colours:** primary green `#15803D`, deep green `#1B5E20`, yellow accent `#FDE047`, soft green `#DCFCE7`, background `#FCFDFA`, text `#1F2937`, warning `#FFF8E1`, danger `#DC2626`
- **Font:** Hind Siliguri, for Bangla and English
- **Navigation:** top bar on desktop, bottom bar on mobile
